# Mindscape

Publish an [Obsidian](https://obsidian.md) vault as a fast, good-looking* static site.

Mindscape is a static site generator (SSG) which understands Obsidian's markdown format (wikilinks, embeds, callouts, comments, code, maths, etc.) and is able to render everything at build time as a Frugiter Aero era website.
